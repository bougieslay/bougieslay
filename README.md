<h3 align="center">Just a developer who likes clean commits.</h3>

I build frontends — mostly React and Next.js, with a lot of TypeScript and Tailwind along the way. Lately I've been drawn to the quieter parts of the craft: how a design system holds together at scale, whether a component actually works for someone using a screen reader, and where the milliseconds are hiding. I don't think I'll ever stop being surprised by how much there is to get right on the web.

#### What I'm up to

- 🔭 A component library that tries to make accessibility the default, not the afterthought.
- 📝 I keep notes about design systems
- 💬 Ask me about React
- ☕ Powered by coffee and late-night commits
